The initial concept focused on reading and displaying individual sensor values. As development progressed, the software evolved into a modular architecture where each sensor was implemented and tested independently before being integrated into the complete system. To improve usability, the OLED interface was redesigned into multiple display states controlled by a push button, allowing the limited display area to present information in a structured manner. Finally, threshold-based logic was introduced to convert raw measurements into meaningful garden advice, resulting in the Version 1.0.0 Smart Garden Helper.
