## Purpose

The Smart Garden Helper is a modular embedded environmental monitoring system developed using the Arduino Grove Beginner Kit and an external DFRobot Gravity Analog Soil Moisture Sensor V2.

The project was designed to demonstrate how multiple sensors can be integrated into a single embedded system capable of monitoring environmental conditions relevant to plant health.

Rather than displaying raw sensor values alone, the system interprets measurements using configurable threshold logic and presents meaningful information through a multi-screen OLED interface.

The software architecture prioritises modularity, readability and maintainability, allowing each subsystem to be developed, tested and understood independently before integration into the final system.
