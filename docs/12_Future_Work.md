# Future Work
## Purpose

The Smart Garden Helper Version 1.0.0 successfully demonstrates how an embedded system can monitor environmental conditions using multiple sensors, interpret those measurements through threshold-based logic, and present meaningful information to the user via a simple OLED interface.

While Version 1.0.0 achieves its intended objectives, it also establishes a strong foundation for future development. The modular software architecture, state-based user interface, and independent sensor modules make the system well-suited for incremental improvements without requiring significant redesign.

This document outlines several possible directions for future work. These ideas range from relatively small software refinements to larger hardware and Internet of Things (IoT) implementations that could transform the Smart Garden Helper into a practical smart agriculture platform.

# Software Improvements
## Configurable Threshold Values

Version 1.0.0 stores all threshold values directly within the source code.

While this approach is appropriate for a prototype, future versions could allow users to modify threshold values without recompiling the software.

Possible approaches include:

Menu-based threshold adjustment,
EEPROM storage,
Serial configuration,
Wireless configuration via a mobile application.

This would allow the Smart Garden Helper to be adapted for different plant species and environmental conditions.

## Improved Decision Logic

The current Plant Advice screen evaluates environmental conditions using a sequence of predefined rules.

Future versions could implement more sophisticated decision-making strategies by considering combinations of sensor measurements rather than evaluating each independently.

Examples include:

Identifying prolonged dry conditions,
Distinguishing between excessive heat and insufficient watering,
Prioritising the most critical environmental issue,
Providing multiple recommendations simultaneously.

Such improvements would make the advice generated by the system more representative of real-world plant monitoring.

## Historical Data Logging

Version 1.0.0 displays only the most recent sensor measurements.

Future versions could record environmental data over time, allowing users to observe trends rather than isolated readings.

Potential information includes:

Hourly temperature changes,
Daily soil moisture variation,
Long-term humidity trends,
Changing light conditions throughout the day.

Historical data would provide a more comprehensive understanding of the monitored environment.

# Hardware Improvements
## Automated Irrigation

One natural extension of the Smart Garden Helper is the addition of automatic watering functionality.

Instead of merely recommending that a plant should be watered, the system could activate a small water pump whenever soil moisture falls below a predefined threshold.

A possible implementation would include:

Miniature DC water pump,
Relay or MOSFET driver circuit,
External power supply,
Configurable watering duration.

This enhancement would transform the Smart Garden Helper from a monitoring system into an automated control system.

## Expanded Sensor Suite

Version 1.0.0 focuses on four environmental measurements.

Future versions could incorporate additional sensors to provide a more complete understanding of growing conditions.

Possible additions include:

Atmospheric pressure,
Rainfall detection,
Ultraviolet intensity,
Soil temperature,
Water level monitoring,
Carbon dioxide concentration,
Wind speed.

These additions would significantly increase the capability of the monitoring system while maintaining the existing modular software architecture.

## Renewable Power

The current prototype is powered through the Arduino's USB connection.

For outdoor deployments, future versions could investigate renewable energy solutions.

Potential improvements include:

Small solar panel,
Rechargeable battery,
Battery management circuitry,
Low-power operating modes.

These enhancements would improve portability while enabling long-term autonomous operation.

# Internet of Things (IoT)
## Wireless Connectivity

Version 1.0.0 operates as a standalone embedded system.

A future version could incorporate wireless communication to enable remote monitoring.

Possible hardware platforms include:

ESP32,
ESP8266,
Wi-Fi-enabled Arduino-compatible boards.

Wireless connectivity would allow sensor measurements to be accessed without requiring physical interaction with the device.

## Cloud-Based Monitoring

Rather than storing measurements locally, future versions could upload environmental data to a cloud platform.

This would enable users to monitor the garden remotely using a computer or mobile device.

Possible features include:

Real-time sensor dashboards,
Historical data visualisation,
Remote notifications,
Threshold alerts,
Multi-device monitoring.

Cloud integration would represent a significant progression from a local monitoring system to a connected smart agriculture platform.

## Mobile and Web Dashboard

A web-based dashboard could provide a more comprehensive overview of the monitored environment than the OLED display alone.

Potential dashboard features include:

Live sensor measurements,
Interactive graphs,
Historical trends,
Device status,
Threshold configuration,
Environmental summaries.

Such a dashboard would also simplify long-term monitoring and data analysis.

# External Data Integration
## Weather Information

Future versions could incorporate publicly available weather forecasts to improve decision-making.

Rather than responding only to current sensor measurements, the system could also anticipate future environmental conditions.

For example:

Delaying irrigation before forecast rainfall,
Identifying periods of extreme heat,
Monitoring prolonged dry conditions,
Providing weather-based recommendations.

Integrating local weather information would allow the Smart Garden Helper to make more informed decisions.

# Intelligent Decision Making
## Machine Learning

Version 1.0.0 uses manually selected threshold values.

As larger quantities of environmental data become available, future versions could investigate machine learning techniques for more advanced decision support.

Possible applications include:

Recognising recurring environmental patterns,
Predicting watering requirements,
Identifying unusual sensor behaviour,
Detecting gradual environmental changes,
Improving recommendation accuracy over time.

Although well beyond the scope of Version 1.0.0, these approaches illustrate how embedded sensing systems can evolve into intelligent monitoring platforms.

## Educational Opportunities

Although the original Sensor School programme has concluded, the Smart Garden Helper remains a valuable educational resource.

The modular design allows individual components to be demonstrated independently, making the project suitable for future outreach activities, introductory embedded systems workshops, or demonstrations of environmental sensing and systems thinking.

Because each subsystem is documented separately, the project can also serve as a reference for students beginning to explore Arduino programming, sensor integration, and embedded software architecture.

## Research Opportunities

The Smart Garden Helper also presents several opportunities for future undergraduate engineering projects and independent research.

Potential areas of investigation include:

Optimisation of sensor calibration techniques,
Comparison of different soil moisture sensing technologies,
Low-power embedded system design,
Wireless environmental monitoring,
Internet of Things architectures,
Smart agriculture applications,
Human-computer interaction in embedded systems.

These topics extend beyond the implementation of Version 1.0.0 and provide opportunities to explore broader engineering challenges.

## Long-Term Vision

Version 1.0.0 demonstrates how a compact embedded system can monitor environmental conditions and provide simple decision support for plant care.

A long-term vision for the Smart Garden Helper is to evolve from an educational prototype into a practical smart gardening platform capable of autonomous environmental monitoring, remote connectivity, and intelligent decision-making.

Such a system could combine environmental sensing, wireless communication, cloud computing, and automation to assist users in maintaining healthier plants while reducing manual intervention.

Although these capabilities extend beyond the objectives of Version 1.0.0, the software architecture developed during this project has been intentionally designed to support future expansion.

## Future Work Summary

The Smart Garden Helper Version 1.0.0 establishes a robust foundation upon which progressively more capable systems can be developed. Future work may focus on enhanced software functionality, expanded sensing capabilities, automated control, wireless connectivity, and cloud-based monitoring, while also exploring opportunities in smart agriculture and embedded systems research.

By maintaining a modular architecture and well-documented codebase, future versions can incorporate these enhancements incrementally without fundamentally altering the underlying design philosophy established in Version 1.0.0.
